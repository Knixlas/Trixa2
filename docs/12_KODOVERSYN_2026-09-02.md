# Kodöversyn 2026-09-02 — coach/ + trixa_api/

Tio granskningsvinklar (tre rad-för-rad-skanningar, invariant-revision,
kontraktsspårning över modulgränser, återanvändning, förenkling, effektivitet,
"rätt djup", CLAUDE.md-konventioner) över 17 400 rader. Varje kandidat
verifierades separat mot citerad kod: **50 av 51 CONFIRMED**, 1 PLAUSIBLE
(beror på prod-miljö), 1 delkandidat refuterad.

Radnummer gäller `main` vid `6cf8845` (före fixarna). Statuskolumnen bär
PR-numret för varje åtgärdat fynd; serien #39–#46 mergades 2026-09-02.
Sammanfattning av vad som ändrar hur koden ska läsas: CLAUDE.md,
"Kodöversyn 2026-09-02".

Tre mönster förklarar merparten och är billigare att åtgärda som mönster:

1. **Sportvokabulären** — tretton oberoende översättningstabeller som redan
   motsäger varandra. Ett register (`coach/trixa/sports.py`) stänger sex fynd.
2. **`except Exception: return []`** i planeraren — sväljer fel där tystnad är
   farligast (Nils-grinden, plan-skrivningen, metrics). Fyra fynd.
3. **Testfaken** där `gte/lte/lt` är no-ops — sviten kan inte se
   datumgränsfel; tio testfiler delar den. Därför var det mesta här osynligt
   trots 215 gröna tester.
