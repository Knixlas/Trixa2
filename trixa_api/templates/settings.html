AI-åtkomst

Vill du att din AI-coach ska läsa din plan och skriva pass åt dig? Skapa en token och lägg in den i AI-klienten. Token låser AI:n till just din data — den ser ingen annans, och du kan återkalla den när som helst.

I Claude Code kopplar du in Trixa med ett kommando:
claude mcp add --transport http trixa {{ base_url }}/mcp --header "Authorization: Bearer <token>"
Andra klienter tar samma adress ({{ base_url }}/mcp) och samma header. Behöver du ett vanligt REST-API istället finns det på /agent.
